# Antigravity CLI in Docker (Remote Access & OpenMediaVault)

[🇵🇱 Wersja w języku polskim (Polish Documentation)](README.pl.md)

Run Google's official **Antigravity CLI (`agy`)** in a self-contained Docker container configured for persistent **Remote Access / Remote Control**.

Specifically designed for home servers and NAS systems like **OpenMediaVault (OMV)**, **Unraid**, **TrueNAS**, **Synology**, and any standard Linux Docker host.

---

## 🌟 Key Features

- **Google Remote Control:** Connects outbound to `https://antigravity.google.com` over a reverse encrypted tunnel — **no port forwarding**, no static public IP needed.
- **Access Everywhere:** Control your server's agent seamlessly from the desktop web app or the mobile PWA on your smartphone/tablet.
- **Built-in Web Terminal (Port 7681):** Perform one-time OAuth authentication directly in your web browser without needing an SSH client.
- **PUID / PGID Permissions:** Compatible with OpenMediaVault / Linux permissions so files generated by the agent belong to your regular user instead of `root:root`.
- **Persistent Sessions:** OAuth tokens, preferences, and conversations persist in a mounted `config` volume (`~/.gemini`).
- **Complete Toolchain:** Pre-installed with `git`, `python3`, `nodejs`, `npm`, `build-essential`, `jq`, and optional `docker.sock` passthrough.

## 🚀 Quick Start

### 1. Clone & Setup
```bash
git clone https://github.com/ar2r27/Antigravity_cli_docker.git
cd Antigravity_cli_docker
cp .env.example .env
```

### 2. Configure PUID & PGID
Check your local user ID:
```bash
id $USER
```
Update `PUID` and `PGID` in `.env` or `docker-compose.yml` if necessary.

### 3. Build & Run
```bash
docker compose up -d --build
```

## 🔑 One-Time Google OAuth Authentication

Once the container starts, it requires a one-time sign-in to associate with your Google Account:

### Method A: Web Terminal (Recommended)
1. Open your browser and navigate to:
   ```text
   http://<YOUR_SERVER_IP>:7681
   ```
2. In the terminal prompt, run:
   ```bash
   agy-login
   ```
3. Click or copy the displayed Google authentication link.
4. Sign in to your Google Account and copy the generated verification code.
5. Paste the code back into the web terminal prompt and press `Enter`.
6. The container detects the successful login and immediately launches the **Remote Control** daemon!

### Method B: Server Terminal (SSH)
Run on the host:
```bash
docker compose exec -it antigravity agy-login
```
Follow the prompts to complete authentication.

## 🌐 Connecting via Remote Access

1. Visit **[https://antigravity.google.com](https://antigravity.google.com)** on your PC, Mac, iPhone, iPad, or Android device.
2. Sign in with the **same Google Account**.
3. In the instance picker (Instance Switcher), select your machine (default: `OMV-Antigravity`).
4. Start coding, dispatch agent tasks, and supervise files directly on your server.

## 🛠️ OpenMediaVault (OMV) Setup

In OpenMediaVault:
1. Navigate to **Services** ➔ **Compose** ➔ **Files**.
2. Click **+** to add a new file (e.g. named `antigravity`).
3. Paste the contents of `docker-compose.yml`, pointing the volumes to your shared folders:
   - Config: `/srv/dev-disk-by-uuid-.../appdata/antigravity/config:/home/antigravity/.gemini`
   - Workspace: `/srv/dev-disk-by-uuid-.../data/projects:/workspace`
4. Click **Save**, then **Up**.
5. Open `http://<OMV_IP>:7681` to perform the initial sign-in.

## ⚙️ Environment Variables

| Variable | Default | Description |
| :--- | :--- | :--- |
| `PUID` | `1000` | Host user ID (run `id <user>` on host) |
| `PGID` | `100` | Host group ID (in OMV `users` group is typically `100`) |
| `TZ` | `Europe/Warsaw` | Container timezone |
| `INSTANCE_NAME` | `OMV-Antigravity` | Device name shown on `antigravity.google.com` |
| `AUTO_START_REMOTE` | `true` | Automatically run `agy remote-control serve` |
| `ENABLE_WEB_TERMINAL`| `true` | Enable web terminal on HTTP port |
| `WEB_TERMINAL_PORT` | `7681` | Web terminal port |
| `WEB_TERMINAL_USER` | *(empty)* | Optional HTTP basic auth username for web terminal |
| `WEB_TERMINAL_PASS` | *(empty)* | Optional HTTP basic auth password for web terminal |
